【观点】南华期货：纸浆、胶版纸期价总体震荡偏弱

抓取时间标记：11月03日 09:47

正文容器：div.news-content.article-content

原始来源：http://goodsfu.10jqka.com.cn/20261103/c681387875.shtml

【期货盘面】前一交易日，纸浆期货（SP）日盘先震荡后下跌，夜盘低开后震荡上行，11-01合约价差为-96元/吨；胶版纸（双胶纸）期货（OP）日盘先涨后跌，夜盘震荡上行，12-01合约价差为20元/吨。

【现货基差】针叶浆现货行情维稳。山东银星报价4800-4820元/吨（0/0），山东乌针、布针报价4620-4700元/吨（0/0），华南银星报价4900元/吨（0）。基差相对扩大，成交热情下降。

【估值利润】据悉，智利Arauco公司最新阔叶浆外盘报价上调20美元至610美元/吨，针叶浆外盘报价上调10美元至680美元/吨，本色浆外盘报价持平，为660美元/吨。

【供需库存】从基本面来看，需求整体变化不大：高价货源接受度进一步下降，下游市场出货承压，开工率进一步走低；国外浆厂新增投产消息再度出现，供应预期相对增加，带来一定压力。但上周国内库存继续下行，带来一定底部支撑。

对于胶版纸期货而言，出版招标仍有所推进，但招标价格偏低，或对市场形成相对偏空影响；社会需求不佳，出货受限。部分停机产能复产，且福建新产能持续投放，供应整体压力仍在。双胶纸原纸库存再度回落，压力有所缓解。

【市场信息】1. 上周中国主要地区及港口（1地区4港口）周度纸浆库存量为201.41万吨，较前一周下降0.39%，降幅收窄0.43%（卓创资讯（301299））。截至10月30日，双胶纸原纸生产企业库存为139.44万吨（-1.48）。（钢联）

2. 上周双铜纸开工负荷率为42.53%，较前一周下降8.80%；双胶纸开工负荷率为41.03%，较前一周下降3.4%，降幅均有所扩大；生活用纸样本企业开工负荷率较前一周下降2.99%，止升回落，产量较前一周减少4.46%（卓创资讯（301299））。

3. 美联储维持联邦基金利率目标区间在3.75%至4.00%不变，库克与哈马克两名票委主张加息25个基点，声明将经济评价由“稳步”上调至“强劲”。沃什称，明年起削减议息会议次数，不预判12月决策，AI投资同样受利率影响。（华尔街见闻）

4. 10月29日，太阳纸业（002078）发布公告，计划在山东颜店厂区建设50万吨/年化学浆和60万吨/年包装纸产能。

【南华观点】如此前所述，上方限制犹在，叠加部分多头止盈离场，昨日期价有所回落。但近期宏观因素、针阔叶价差也带来一定底部支撑，期价总体波动较小。预计纸浆和胶版纸期价延续震荡或震荡偏弱走势。
