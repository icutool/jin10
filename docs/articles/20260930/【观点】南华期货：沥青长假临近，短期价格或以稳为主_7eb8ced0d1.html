【观点】南华期货：沥青长假临近，短期价格或以稳为主

抓取时间标记：09月30日 09:31

正文容器：div.news-content.article-content

原始来源：http://goodsfu.10jqka.com.cn/20260930/c680392223.shtml

【期货盘面】沥青主力合约震荡偏强运行，国际原油及沥青期货价格上涨提振成本端与市场情绪，叠加国内现货供应紧缺格局延续，市场推涨情绪升温，山东、华南地区现货价格领涨，东北社会库价格跟随上调。但国庆假期临近，叠加部分地区降雨天气偏多，下游施工进度放缓，市场成交气氛整体一般，价格大幅上行空间有限。近月合约受低供应、低库存格局强力托底；远月重点跟踪国庆假期后终端需求恢复节奏及炼厂复产排产进展，盘面需警惕国际原油波动、假期需求走弱带来的调整风险。

【现货基差】9月29日国内沥青市场均价6496元/吨，较上一日上涨40元/吨，涨幅0.62%。原油及沥青期货价格上涨，叠加国内供应紧缺利好，提振市场推涨情绪，山东及华南地区沥青价格继续上涨。此外，受周边沥青价格走高带动，东北社会库价格小幅上调。但临近假期，且部分地区降雨天气较多，下游施工进度缓慢，市场成交气氛一般。

【供需库存】供应端全国整体资源维持偏紧格局，西北主力炼厂产销平稳；华北主力炼厂持续限量发货，库存处于低位，10月合同签订接近尾声；山东多数地炼维持限量出货，月底贸易商合同逐步执行完毕；长三角主力炼厂处于停产状态；华南中油高富沥青停产，短期供应量进一步缩减，当地社会库存水平极低。需求端国庆假期将至，中下游用户补货需求逐步转弱，叠加部分地区降雨干扰施工，下游采购趋于谨慎，成交多集中在低端，整体成交气氛一般。库存端全国炼厂及社会库存整体处于低位，华南地区社会库存降至极低水平，对沥青价格形成底部支撑。

【市场信息】1. 西北市场：主流成交价持稳6050—6700元/吨。疆内主力炼厂产销平稳，但前期区内价格连续上涨后，资源外流受阻，成交乏力，昨日个别中石化炼厂沥青价格下调100元/吨以促成交。今日周边地区受成本端走强带动，价格有所上涨，对西北市场心态形成一定支撑。短期看，需求有限，但周边高价支撑仍存，预计西北沥青价格维持坚挺运行。

2. 东北市场：主流成交价上涨25元至6400—6450元/吨。今日江苏炼厂低硫沥青放量，东北主力炼厂继续交付合同，低硫沥青价格暂稳；道路方面，假期临近，下游刚需采补，周边沥青价格宽幅上涨，利好东北沥青价格上推，部分社会库低价资源价格上调。短期，赶工刚需仍有支撑，且周边价格高位支撑，沥青价格或维稳为主。

3. 华北市场：重交沥青主流成交价持稳6500—6600元/吨。本周区内主力炼厂持续限量发货，库存处于低位，10月合同签订接近尾声，合同价保持坚挺。今日原油及沥青期货价格上涨，现货市场推涨情绪升温，今日贸易商出货价有所走高，部分刚需支撑成交。短期来看，炼厂将延续限量发货，现货资源偏紧，区域沥青价格预计维持坚挺。

4. 山东市场：主流成交价上涨40元至6300—6350元/吨。原油及沥青期货盘面价格上涨，叠加月底部分贸易商合同基本执行完毕，市场推涨情绪升温，多数地炼沥青价格上涨至6200—6350元/吨。不过临近假期，需求端利好不足，且美伊局势不稳，中下游用户采购谨慎，成交多集中在低端，短期沥青价格或谨慎走稳。

5. 长三角市场：主流成交价持稳6600—6750元/吨。降雨天气以及高价影响项目施工，叠加假期临近，贸易商出货量稀少，虽然周边市场价格走高，且当地社会库存水平降至历史低位，但近两日镇江以及南京贸易商价格暂时保持稳定。短期，主力炼厂处于停产状态，供应紧缺下支撑区内沥青价格坚挺。

6. 华南市场：主流成交价上涨100元至6550—6600元/吨。中油高富沥青停产，当地社会库存水平极低，短期供应量进一步缩减。同时，原油及沥青期货价格上涨，周边现货市场价格上涨，带动华南地区推涨情绪持续升温，今日当地贸易商继续上调出货价。虽然受假期影响，需求减弱，但供应紧张将支撑沥青价格短期保持坚挺。

【南华观点】当前沥青市场供应紧缺的核心支撑逻辑未变，炼厂低产、社会库存低位叠加原油价格上涨，共同提振市场挺价情绪，现货价格维持高位偏强运行。但国庆假期临近，终端施工逐步放缓，中下游补货需求转弱，叠加部分地区降雨干扰，市场成交整体一般，进一步大幅上行空间有限，短期价格或以稳为主。后续重点跟踪国庆假期后终端道路施工恢复情况、炼厂复产及排产节奏以及国际原油价格波动。
