【观点】正信期货研究院：IF、IH配置价值更稳，建议积极做多

原始来源：http://goodsfu.10jqka.com.cn/20260615/c677456301.shtml

上周A股继续缩量震荡，沪指失而复得4000点，深成指（399001）和创业板指（399006）仍偏弱，周成交13.95万亿元，市场主线仍在高位科技与低位轮动之间反复切换，上周五美股在油价回落和SpaceX（SPCX）首秀带动下收涨，标普500（SPX）、道指、纳指分别涨0.5%、0.7%、0.3%。周末最重要的变化来自地缘缓和预期升温，特朗普宣布美伊已达成和平协议并将重开霍尔木兹海峡，伊朗也确认了协议但称要到正式签署后才开始执行，市场由此交易原油供给中断风险下修、美国通胀压力回落；从动机看，白宫显然也希望借协议压低油价、缓和通胀和民意压力，而这解释了为什么油价和风险偏好会同步修复，不过协议仍有核问题和执行细节待谈，本周联储议息前，美国5月CPI同比4.2%、核心2.9%的高通胀背景并未消失，若地缘再反复或美联储偏鹰指引，利率和油价仍可能回摆，反之，则本轮金融条件抑制的调整有望见底。国内看，半导体（881121）、PCB、算力租赁（886050）、服务器等方向仍是资金围绕业绩与国产替代反复博弈的核心，A股短期大概率延续权重托底、成长分化修复的格局。

观点汇总：短期留意联储与美伊协议反复，IC、IM弹性仍在，建议波段参与；长期慢牛未改，IF、IH配置价值更稳，建议积极做多。
