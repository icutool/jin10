【观点】南华期货：纸浆和胶版纸短期震荡偏弱

抓取时间标记：10月27日 09:22

正文容器：div.news-content.article-content

原始来源：http://goodsfu.10jqka.com.cn/20261027/c681117298.shtml

【期货盘面】前一交易日纸浆期货（SP）日盘先跌后涨，夜盘开盘大幅下行，后先跌后涨，11-01合约价差为-108元/吨；胶版纸（双胶纸）期货（OP）日盘震荡，夜盘开盘大涨，后明显回落，11-12合约价差为-22元/吨。

【现货基差】针叶浆现货行情维稳。山东银星报价4750元/吨（0/0），山东乌针、布针报价4600-4650元/吨（0/0），华南银星报价4900元/吨（0）。基差相对增长，成交热情下降。

【估值利润】据悉，智利Arauco公司最新阔叶浆外盘报价上调20美元，为610美元/吨；针叶浆外盘报价上调10美元，为680美元/吨；本色浆外盘报价持平，为660美元/吨。

【供需库存】从基本面来看，下游市场需求不及此前预期，“旺季不旺”，纸厂加工需求承压，市场以压价询单为主，开工率进一步走低；国外部分浆厂可能复产，且有纸浆厂新增投产，供应预期相对增加，带来一定压力。但上周国内库存有所回落，带来一定底部支撑。

对于胶版纸期货而言，出版招标仍有所推进，但整体需求不佳，市场仍以观望为主，出货受限；江苏、江西和山东地区部分产线开工下滑，供应压力有所减小，但福建新产能持续投放，供应整体压力仍在。双胶纸原纸库存小幅增长，压力相对增加。

【市场信息】1. 上周中国主要地区及港口（1地区4港口）周度纸浆库存量202.19万吨，较前一周环比下降0.82%（卓创资讯（301299））。截至10月23日，双胶纸原纸生产企业库存140.92万吨（+0.4）。（钢联）

2. 上周双铜纸开工负荷率在51.33%，较前一周环比下降3.41%；双胶纸开工负荷率在44.42%，较前一周下降0.75%；生活用纸样本企业开工负荷率较前一周上升0.67%；产量预估较前一周增加1.08%（卓创资讯（301299））。

3. 华堡纸业、鸿起纸业均官宣，自2026年11月1日起在现有成品纸供应价格上调50元/吨。（隆众资讯）

【南华观点】国外浆厂新增投产或复产带来的供应偏空影响与大量老旧仓单压制期价上限，但针阔叶价差等因素带来底部支撑。预计纸浆和胶版纸期价短期延续震荡偏弱，中期存在触及低位后有所反弹的可能性。
