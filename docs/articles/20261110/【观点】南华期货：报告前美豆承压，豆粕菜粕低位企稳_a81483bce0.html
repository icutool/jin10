【观点】南华期货：报告前美豆承压，豆粕菜粕低位企稳

抓取时间标记：11月10日 09:33

正文容器：div.news-content.article-content

原始来源：http://goodsfu.10jqka.com.cn/20261110/c681639688.shtml

【期货盘面】CBOT大豆（885810）上周五小幅反弹后周一再度收跌，仍处7月下旬以来震荡区间下沿，美国农业部周二发布11月供需报告，市场普遍预期上调美豆单产与产量，丰产预期继续压制盘面；ICE菜籽此前连跌四个交易日且跌幅逐日收窄，周一止跌收高，仍处6月底以来低位区间，加拿大谷物委员会周度出口与国内用量数据向好，抵消油脂板块走弱压力；豆粕主力两连跌、最近一日跌幅明显收窄，回落至8月上旬震荡区间下沿，现货报价偏弱、成交均价续降，现货成交回升但远月基差缩量；菜粕主力近三日在低位宽幅震荡、周一再度收涨，仍处近半年低位区，现货报价持稳、库存处于低位限制下方空间。

【现货基差】43%豆粕现货大连3180（0），天津3160（+10），日照3060（0），南通3040（-10），东莞3020（-20）；日照01基差25（-16），东莞01基差5（-16）；天津-江苏价差120（+20），山东-江苏价差20（+10），广东-江苏价差-20（-10）。菜粕现货广东2370（0），华东2280（0），福建2280（+10）；广东01基差157（-13），华东01基差67（-13）（元/吨，较上一交易日）。

【估值利润】巴西大豆（885810）CNF对盘压榨利润-60.4（+0.6），美湾大豆（885810）CNF对盘压榨利润-70.8（+0.6）；加拿大菜籽盘面榨利-162.8（+6.8），加拿大进口油菜籽现货榨利69（-6）（元/吨）。

【供需库存】豆粕日度总成交12.27万吨（+1.82），其中现货成交6.27万吨（+2.32）、远月基差成交6.00万吨（-0.50），平均成交价3131元/吨（-7）；菜粕成交0吨；大豆（885810）压榨厂开机率51.7%（+0.3），油菜籽压榨厂开机率29%（+2）；豆粕周度库存118.69万吨（-4.90），菜粕周度库存1.52万吨（+0.02）。

【市场信息】1. USDA出口检验周报：截至11月5日当周美国大豆（885810）出口检验190万吨，较前一周的251万吨回落，但高于去年同期的112万吨，本年度累计1415万吨，远高于上年同期的893万吨，中国为当周主要买家。（USDA）

2. 市场预期周三发布的USDA 11月供需报告将美豆单产上调至53.6蒲式耳/英亩（10月为53.1），产量上调至46亿蒲式耳（10月为45.6亿蒲），报告前市场承压。（道琼斯）

3. 加拿大谷物委员会：截至11月1日当周菜籽出口28.49万吨、国内用量25.11万吨，均较前周改善，本年度累计出口近221万吨、国内用量324万吨，均快于上年同期。（加拿大谷物委员会）

4. StoneX（SNEX）：阿根廷玉米（885811）与大豆（885810）产区生长条件目前良好，巴西大豆（885810）生长状况同样良好，12月进入结荚期后南美天气仍存变数。（StoneX（SNEX））

【南华观点】后市来看，供应端，美豆收割接近尾声，市场在等待USDA11月报告进行定产，同时目前美豆主要是非商业性采购，商业采购暂未放开；巴西大豆（885810）则正值播种期，目前播种进度已达到53%，因天气原因，各州快慢不一。需求端来看，出口方面，巴西雷亚尔贬值使得进口成本下移，内盘成本支撑相应减弱，美豆2500万吨采购目前还剩600多万吨尚未完成。生柴需求方面，宏观形势有好转趋势，原油价格有所下跌，同时EPA对2026年和2027年的配额分配方案仍存在不确定性。菜粕方面，供应端，加拿大菜籽收割基本完成，但较澳大利亚菜籽的关税更高，在澳籽目前较充裕的情况下难有替代，需求端，目前正处水产养殖（884006）淡季，支撑进一步减弱。
