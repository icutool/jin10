【观点】南华期货：沥青低供应支撑，价格高位震荡

抓取时间标记：09月22日 09:19

正文容器：div.news-content.article-content

原始来源：http://goodsfu.10jqka.com.cn/20260922/c680152589.shtml

【期货盘面】沥青主力合约高位震荡整理，国际原油期货走弱拖累市场情绪，山东、华北需求表现一般，现货推涨乏力，部分贸易商出货价略有松动；但国内整体供应紧张格局未改，社会库存降至低位，对盘面形成底部支撑。当前现货价格处于历史高位，高价持续抑制终端需求，中下游采购积极性下降。近月合约受低供应格局托底；远月重点跟踪炼厂复产放量节奏，盘面需警惕原油持续回落叠加需求走弱带来的调整风险。

【现货基差】9月21日国内沥青市场均价6431元/吨，较上一日下跌13元/吨，跌幅0.20%。市场呈现区域分化，南方部分保供项目支撑需求，主营炼厂开工仍存下降预期，且社会库存水平降至低位，支撑炼厂及贸易商价格坚挺，今日华南中石化沥青价格上调60-80元/吨；山东、华北市场需求一般，叠加原油期货价格下跌，现货市场推涨乏力，部分贸易商出货价略有松动，但供应紧张仍对价格形成支撑，主流价格基本维持稳定。

【供需库存】供应端全国整体仍维持偏紧格局，西北主力炼厂限量发货，华北炼厂继续限量发货并推涨10月合同价；山东部分炼厂限量及排队情况有所缓解；长三角主营炼厂产量偏低，浙江个别炼厂停产，江苏资源计划调入补充当地缺口；华南资源仍较为紧缺。库存端社会库存持续降至低位，对价格形成支撑。需求端分化明显，南方保供项目形成一定支撑，山东、华北需求表现一般，长三角多数终端项目推迟或停工，华南用户观望情绪较重，整体高价抑制需求，中下游采购积极性有所下降。

【市场信息】1. 西北市场：主流成交价持稳5720-6700元/吨。当前疆内主力炼厂限量发货，整体资源供应偏紧；同时，部分项目赶工带来一定需求支撑，而社会库存处于低位，供需双紧。短期内，区域内供给偏紧格局难以缓解，叠加周边市场价格高位震荡，西北地区沥青价格整体坚挺。

2. 东北市场：主流成交价持稳6500-6600元/吨。炼厂交付合同为主，且今日区外低硫沥青放量，市场等待其价格落地，今日区内主力炼厂报价暂稳，后期或跟随周边低硫价格上涨；道路方面，河北炼厂沥青价格继续上调，导致当地送到成本上涨，带动个别社会库价格小幅上调，不过山东、河北部分贸易商价格小幅走跌，区内主流社会库观望暂稳。短期，受供应及刚需托底，沥青价格继续坚挺。

3. 华北市场：主流成交价上涨50元至6500-6600元/吨。货源维持偏紧格局，炼厂10月沥青合同价继续推涨50元/吨，目前仍限量发货，不过今日期货盘面走弱，市场推涨情绪有所降温，因此当地贸易商出货价略有松动。短期来看，供应仍偏紧，部分刚需释放对行情形成支撑，价格整体保持坚挺。

4. 山东市场：主流成交价下跌80元至6270-6300元/吨。油价回落，市场观望情绪加重，另外，部分炼厂限量及排队情况有所缓解，因此部分贸易商降价让利出货，带动市场主流成交重心下移。短期看，原料导致的供应紧张问题仍然存在，但价格高位下终端用户采购积极性一般，沥青价格或暂时走稳。

5. 长三角市场：主流成交价持稳6500-6600元/吨。受沥青高价影响，大多终端项目推迟或者停工，需求表现疲软，但社会库存目前已降至极低水平，对价格有支撑，个别贸易商今日出货价小幅走高。此外，由于主营炼厂沥青产量偏低，浙江个别炼厂沥青停产，部分江苏炼厂资源近日计划移至浙江地区，以补充当地资源供应缺口。

6. 华南市场：主流成交价持稳6360-6400元/吨。昨日中石油竞拍价格落地后，带动当地市场价格上涨，佛山（883403）库出货报价涨至6360-6400元/吨，价格过高导致当地多数用户观望情绪加重，不过短期市场资源仍较为紧缺，支撑价格保持高位坚挺。

【南华观点】当前沥青市场低供应、低库存的核心支撑逻辑仍在，现货价格整体维持历史高位；但原油走弱叠加高价持续抑制终端需求，中下游采购积极性下降，部分区域贸易商报价松动，市场进入高位震荡阶段。短期供应偏紧格局难以快速扭转，对价格仍形成底部支撑，但若需求持续走弱，不排除部分货源让利出货的可能。后续重点跟踪炼厂复产放量进度、国际原油价格波动以及终端道路需求恢复情况。
