【观点】南华期货：玉米止跌企稳，淀粉现货补跌，预计玉米区间震荡、淀粉偏弱整理

抓取时间标记：11月18日 09:18

原始来源：http://goodsfu.10jqka.com.cn/20261118/c681934732.shtml

【期货盘面】上一交易日玉米（885811）主力合约 c2701 止跌企稳，日盘收于 2177 元/吨，上涨 3 元/吨，涨幅 0.14%，结束此前三连阴，重心维持在 2180 元/吨附近；淀粉主力合约cs2701 窄幅偏弱，收于 2460 元/吨，下跌 3 元/吨，跌幅 0.12%，在 2460 元/吨一线整理。玉米（885811）-淀粉价差 -283 元/吨，较前一交易日收窄 6元/吨，负价差仍处历史偏低水平。

【现货基差】玉米（885811）现货价（元/吨）及变化：哈尔滨 2105（0）、长春 2170（0）、锦州港 2225（0）、蛇口港 2320（0）、潍坊 2220（0）、德州 2270（+10），东北产区、南北港口与山东止跌企稳，仅德州小幅上调。玉米（885811）主力基差：哈尔滨 -72（-3）、锦州港 +48（-3）、蛇口港 +143（-3），随盘面小幅反弹同步收敛 3 元/吨。淀粉现货价（元/吨）及变化：山东 2710（0）、吉林 2630（-20）、黑龙江 2530（-20）、河南 2800（0）、全国均价 2683（-5），东北两省补跌、山东与河南持稳。淀粉主力基差：山东 +250（+3）。

【供需库存】玉米（885811）供应端，新作上市量继续增加，基层售粮节奏平稳，贸易环节以流量贸易为主、主动建库意愿偏弱，北港到货充裕，全国主要港口库存合计 329.0 万吨、周环比增加 27.5 万吨，累库节奏延续；需求端，深加工周度消费（883434）量 125.40 万吨、环比减少 0.14 万吨，高位持稳；深加工企业库存 295.3 万吨、环比减少 9.9 万吨，由累转降，企业压价收购与刚需补库并存；饲料养殖端随用随采，建库意愿不高。淀粉端，最新一周行业开工率 63.15%、环比提升 0.90 个百分点，供应继续抬升；企业物理库存 136.0 万吨、环比增加 1.2 万吨，连续第三周累积；山东加工利润 -69 元/吨、亏损较前值 -63 元/吨再度扩大，河北 50 元/吨、小幅修复 2 元/吨。

【南华观点】玉米（885811）端，深加工企业库存转降、北港收购价止跌与基层售粮节奏平稳构成支撑，但港口库存累积、进口利润高企与替代谷物充足压制反弹，预计盘面维持区间震荡。淀粉成本下移与提价乏力并存，预计跟随玉米（885811）偏弱整理。
