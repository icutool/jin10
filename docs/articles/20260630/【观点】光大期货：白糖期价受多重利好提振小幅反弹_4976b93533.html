【观点】光大期货：白糖期价受多重利好提振小幅反弹

抓取时间标记：06月30日 09:13

正文容器：div.news-content.article-content

原始来源：http://goodsfu.10jqka.com.cn/20260630/c677821619.shtml

消息方面，俄罗斯农业市场研究所：预计俄罗斯2026/27榨季甜菜种植面积超过115万公顷（约1725万亩），同比减少3万公顷（约45万亩）；预计2026/27榨季产糖量为630万吨，同比减少10万吨；预计2026/27榨季出口食糖110万吨，同比减少15万吨。现货报价方面，广西制糖集团报价区间5240~5350元 / 吨，部分下调 10元 / 吨；云南制糖集团报价5040~5120元 / 吨，英茂上调 10元 / 吨、南华报价持平；加工糖厂主流报价区间为5590~6050元 / 吨，整体报价持平。欧洲热浪来袭，市场担忧甜菜长势受到影响，进而影响最终糖产量，受此提振，原糖期价持续反弹，未来继续关注天气对于东南亚、巴西农作物的影响。国内关于预混粉进口的消息引发关注，据市场消息，严禁老挝新的糖浆厂在华注册、严查预混粉进口原产地信息。市场理解为将有效管控第三方糖转口生产成预混粉进口的问题。期价受到提振小幅反弹，未来关注国内销售进度。
