【观点】南华期货：美豆止跌上涨，豆粕与菜粕低位分化

【期货盘面】CBOT大豆（885810）收盘上涨，因周度出口销售数据处于市场预估区间的高端，抵消了逐渐消退的收割压力。内盘分化，豆粕小幅跟涨，菜粕则受基本面压制小幅收低，跌势放缓

【现货基差】43%豆粕市场价（元/吨）：大连3350（-10）、天津3270（-30）、日照3200（0）、南通3190（0）、东莞3200（0）。豆粕01合约基差（元/吨）：日照+11（-26）、东莞+31（-6）。区域价差（元/吨）：天津-江苏80（-30）、山东-江苏10（0）、广东-江苏10（0）。菜粕方面，地区现货均价（元/吨）：广东2420（0）、华东2360（0）、福建2340（-10）；01合约基差（元/吨）：广东+172（+18）、华东+112（+18）。

【估值利润】进口大豆（885810）压榨利润延续亏损（元/吨）：巴西大豆（885810）CNF对盘压榨利润-76.14（-14.98），美湾大豆（885810）CNF对盘压榨利润-86.87（-1.15）。菜籽端，加拿大菜籽盘面榨利-161.07（+54.54）；加拿大进口油菜籽现货榨利-32（+29）。

【供需库存】成交方面，全国主要油厂豆粕日度总成交47.86万吨（+25.08），其中现货成交8.51万吨（+1.09）、远月基差成交39.35万吨（+23.99）；豆粕平均成交价3286元/吨（-10）。菜粕成交4500吨，菜粕均价2425元/吨（+1）。开机方面，我国大豆（885810）压榨厂日度开机率61.66%（-1.52）；我国油菜籽压榨厂日度开机率34%（0）。库存方面，我国压榨厂豆粕周度库存97.90万吨（+1.72）；我国压榨厂菜粕周度库存2.16万吨（-0.30）。

【市场信息】1. USDA周度出口销售：截至10月15日当周，美国2026/27年度大豆（885810）出口净销售284.1万吨（前一周57.5万吨），其中对中国净销售217.9万吨（前一周12.6万吨）。（USDA）

2. USDA单日出口销售：民间出口商报告向中国出口销售20.2万吨大豆（885810），均于2026/27年度交付。（USDA）

3. USDA干旱监测：截至10月20日，美国大豆（885810）产区处于中度及以上干旱的比例为27%（上周26%）。（USDA）

4. Abiove：受国内加工需求走强影响，预计巴西2027年大豆（885810）出口量较2026年下降0.8%至1.13亿吨；2027年大豆（885810）压榨量预计达创纪录的6600万吨，豆粕出口量预计增长4%至2630万吨。（Abiove）

【南华观点】豆粕端，供应端美豆已进入收获中后期，收割率快于市场预期；南美播种顺利，Conab预估新季产量1.816亿吨、同比增长0.7%，远期供应压力上升。需求端出口方面，中方累计已采购美豆超1500万吨，约定的2500万吨目标仍有约四成尚未完成，政策性采购通道仍在运行；生柴需求方面，17.6亿RIN分配方案仍存在不确定性。菜粕端，供应端加菜籽收割基本完成，四季度菜籽到港压力上升；需求端水产需求支撑逐渐减弱，菜粕性价比优势随豆菜粕价差收窄而下降。
