【观点】南华期货：PX、PTA短期预计震荡偏弱，聚酯需求改善有限

抓取时间标记：11月06日 09:25

正文容器：div.news-content.article-content

原始来源：http://goodsfu.10jqka.com.cn/20261106/c681533683.shtml

【供需库存】供应：PX负荷在79.4%（-1.6%），PTA负荷在69.7%（-2.5%）。

需求：当前聚酯装置负荷小幅提升，聚酯开工率在77.7%左右。江浙织机开机率维持在52%附近，江浙加弹综合开工率维持在61%，印染（884130）开机率在66%。江浙涤丝昨日产销整体清淡，至下午4点附近平均产销估算在2-3成。

库存：当前PTA社会库存约176.45万吨，环比上期上升3.21万吨。

【市场信息】1. 华南一套250万吨PTA装置按计划已于近日停车检修。（CCF）

2. 中国台湾一套70万吨PTA装置已于10月底停车，预计11月下旬重启。（CCF）

3. 安徽某直纺涤短工厂计划近日开一条100吨/天棉型短纤生产线。（CCF）

4. 江苏某直纺涤短工厂近日将重启一条65吨/天棉型短纤生产线。（CCF）

【南华观点】夜盘PX、PTA延续弱势，前期原油大幅下跌带来的成本压力仍在，尽管隔夜油价有所反弹，但聚酯链整体修复力度有限。PX方面，国内装置负荷进一步回落至80%以下，供应端有所收缩，但现货价格持续下跌，前期成本支撑减弱仍对盘面形成压力。PTA方面，近期部分装置停车检修，负荷再次回落至70%以下，对前期装置重启带来的供应增量形成一定对冲，但社会库存仍有累积压力，现货基差继续走弱。随着PX、PTA价格同步回落，PTA加工费小幅收缩，成本下行未能明显改善自身供需格局。需求端聚酯负荷小幅提升，但终端织造开工仍偏低，涤丝产销弱，实际需求改善有限。整体来看，PX、PTA供应端均有一定减量，但当前价格仍主要受到原油及地缘局势波动影响，短期预计维持震荡偏弱，后续重点关注原油走势、PX及PTA装置变化和下游需求表现。
