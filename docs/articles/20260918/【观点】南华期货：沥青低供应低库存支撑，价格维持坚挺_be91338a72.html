【观点】南华期货：沥青低供应低库存支撑，价格维持坚挺

抓取时间标记：09月18日 09:27

正文容器：div.news-content.article-content

原始来源：http://goodsfu.10jqka.com.cn/20260918/c680043181.shtml

【期货盘面】沥青主力合约高位偏强震荡，国际原油高位运行，为沥青提供成本端支撑；国内重质原料不足，导致现货供应维持低位，南北社会库存持续下降至极低水平，炼厂与贸易商惜售情绪浓厚，支撑盘面偏强运行。当前现货价格延续涨势，但高价对终端需求抑制明显，部分区域有价无市，整体成交以刚需为主，进一步大幅上行动力有限。近月合约受低供应、低库存格局强力托底；远月重点跟踪山东等地炼厂复产放量节奏，盘面需警惕原油回落叠加需求走弱带来的调整风险。

【现货基差】9月17日国内沥青市场均价6250元/吨，较上一日上涨68元/吨，涨幅1.10%。沥青价格延续涨势，虽然高价对需求有抑制，但当前北方终端赶工刚需提供一定底部支撑，且近日山东个别炼厂不发货，多数炼厂限量发货，南北方整体社会库存持续下降至极低水平，国内炼厂及贸易商惜售情绪浓厚，今日山东、东北、华南及长三角地区沥青价格继续上涨。

【供需库存】供应端受重质原料不足约束，短期沥青供应仍维持低位；山东主营炼厂尚未恢复生产，地炼多停出或限量发货，西北主力炼厂虽已复产但出货量有限，整体资源偏紧格局未改。库存端南北社会库存持续下降至极低水平，炼厂库存同步处于低位，业者惜售情绪浓厚。需求端北方终端赶工刚需形成一定支撑，但高价普遍抑制终端需求，长三角市场有价无市特征显现，华南用户观望情绪加重，整体成交以刚需为主，需求表现相对一般。

【市场信息】1. 西北市场：主流成交价持稳于5720-6500元/吨。疆内主力炼厂虽已复产，但当前出货量有限，区内资源偏紧局面尚未缓解，疆外市场货源紧张且价格持续走高，对西北市场价格有支撑。区内有一定赶工需求，短期区内供应缺口依旧存在，在周边价格走高的带动下，西北地区价格保持坚挺。

2. 东北市场：主流成交价上涨25元/吨至6150-6200元/吨。炼厂生产平稳，以稳价交付合同为主，低硫沥青价格坚挺；道路方面，赶工刚需支撑贸易商出货，社会库存处于低位，加之周边地区沥青价格上涨，带动成交低端价格上移。短期社会库存处于低位，贸易商主供项目，沥青价格或以稳为主。

3. 华北市场：主流成交价持稳于6100-6200元/吨。区内主力炼厂合同价稳定，延续限量发货，叠加山东主力地炼仍未恢复发货，多数地炼限量发货，资源紧缺格局延续。今日当地贸易商报价有所上涨，下游以刚需采购为主。短期来看，供应偏紧对价格形成较强支撑，预计华北沥青价格维持坚挺运行。

4. 山东市场：主流成交价上涨50元/吨至6100-6150元/吨。主营炼厂沥青尚未恢复生产，地炼亦保持停出或限量出货。在供应紧张的驱使下，沥青价格推涨至6000元/吨以上，带动市场主流成交重心继续上移。短期看，炼厂供应及库存低位的状态持续，沥青价格或保持坚挺，但油价回落加重市场观望情绪，下游用户采购以刚需为主。

5. 长三角市场：主流成交价上涨75元/吨至6400-6550元/吨。主营炼厂按计划量发货，沥青价格坚挺。终端受高价沥青影响，大多项目停工，需求一般，个别镇江贸易商虽报价6400元/吨，但成交欠佳，市场呈现有价无市。后市社会库存及炼厂库存均处于低位，沥青价格走势坚挺。

6. 华南市场：主流成交价上涨175元/吨至6250-6300元/吨。昨日个别中石油炼厂竞拍溢价较高成交，大幅拉涨当地市场出货价格，佛山（883403）库出货报价上涨至6300元/吨左右。价格大幅上涨带动当地多数用户观望情绪加重，但短期供应紧缺局面暂无缓解，支撑价格保持高位坚挺。

【南华观点】当前沥青市场低供应、低库存的核心支撑逻辑未变，叠加原油高位运行，成本端支撑坚挺，现货价格延续涨势并维持历史高位。但高价对终端需求的抑制效应持续显现，部分区域出现有价无市特征，市场成交以刚需为主，进一步大幅上行动力有所减弱。短期重质原料不足约束供应释放，沥青价格整体仍将维持坚挺运行；后续重点跟踪山东等地炼厂复产进度、原油价格波动以及终端道路需求恢复情况。
